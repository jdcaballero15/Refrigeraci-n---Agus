# E99-02 Envío del informe mensual por WhatsApp

## Historia

**Como** administración, **quiero** enviar el informe mensual también por WhatsApp, **para** llegar a clientes que no leen el mail.

## Criterios de aceptación

1. **Dado:** un cliente con teléfono cargado. **Cuando:** se genera el informe. **Entonces:** recibe el aviso por WhatsApp con el enlace o archivo.

## Notas técnicas

- Requiere un servicio de mensajería con costo mensual. Se evalúa en una segunda fase.
